# Facebook Clone

A full-featured social media web application inspired by Facebook, built as part of my Master of Computer Applications (MCA) coursework. This project replicates core social networking functionalities, allowing users to connect, share updates, and interact in real time.

## 🚀 Features

* **User Authentication:** Secure user registration, login, and session management.
* **Dynamic Feed:** Create, view, edit, and delete posts/status updates.
* **Interactive Engagement:** Like, comment on, and share posts with other users.
* **User Profiles:** Personalized profile pages showcasing user details and activity.
* **Responsive Design:** A clean, mobile-friendly interface styled after modern social media platforms.
